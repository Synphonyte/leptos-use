# leptos-use-preferences

Reactive prefers-color-scheme / prefers-contrast / prefers-reduced-motion for Leptos

Part of the [Leptos-Use](https://leptos-use.rs) collection of essential [Leptos](https://leptos.dev) utilities.

```shell
cargo add leptos-use-preferences
```

```rust,ignore
use leptos_use_preferences::{use_preferred_contrast, use_preferred_dark, use_preferred_dark_with_options, use_prefers_reduced_motion, use_prefers_reduced_motion_with_options};
```
