# leptos-use-is

Reactive is_ok / is_err / is_some / is_none signals for Leptos

Part of the [Leptos-Use](https://leptos-use.rs) collection of essential [Leptos](https://leptos.dev) utilities.

```shell
cargo add leptos-use-is
```

```rust,ignore
use leptos_use_is::{is_err, is_none, is_ok, is_some};
```
