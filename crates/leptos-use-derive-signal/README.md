# leptos-use-derive-signal

Macro to create helper functions that derive a Leptos signal

Part of the [Leptos-Use](https://leptos-use.rs) collection of essential [Leptos](https://leptos.dev) utilities.

```shell
cargo add leptos-use-derive-signal
```

```rust,ignore
use leptos_use_derive_signal::{use_derive_signal};
```
