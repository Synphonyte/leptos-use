# leptos-use-math

Reactive math functions for Leptos

Part of the [Leptos-Use](https://leptos-use.rs) collection of essential [Leptos](https://leptos.dev) utilities.

```shell
cargo add leptos-use-math
```

```rust,ignore
use leptos_use_math::{use_abs, use_and, use_ceil, use_floor, use_max, use_min};
```
